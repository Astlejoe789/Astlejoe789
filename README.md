### 3. [DermaKnight — Skin Lesion Classification & Interpretability](https://github.com/Astlejoe789/DermaKnight)
A deep learning computer vision pipeline utilizing MobileNetV2 for dermatological lesion classification, coupled with Grad-CAM visual explanation heatmaps to verify model decision regions.

- **Focus**: Convolutional neural networks, transfer learning, and model interpretability with Grad-CAM.
- **Technologies**: `Python` · `TensorFlow` · `OpenCV` · `Scikit-learn` · `Streamlit`
- [Explore Repository →](https://github.com/Astlejoe789/DermaKnight)

### 4. [StudyTrack — Student Study Habit Recommender](https://github.com/Astlejoe789/Study-Track-AI-Based-Student-Study-Habit-Recommender)
